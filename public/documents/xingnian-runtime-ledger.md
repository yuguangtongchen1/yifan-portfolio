## A. 总则（稳定段 · 禁止写入状态）

### A-1 CLAUDE.md定位

- 谋主 Loop 的运行时内存：状态指针、转移守卫、产物结构的唯一载体

### A-2 维护规则

1. **行按需增减**：行由执行时增减；题注「≥N」是下限，不是预置行数
2. **ID 终身不变**：删旧行/插新行时不重排，续最大序号，保证引用不串混
3. **输入须溯源**：下游输入标来源——上游产物引「Lxx」，主公/工作区/外部信源标注出处
4. **全部产物必须交代**：每个产物要么产出内容，要么在其表内注明"条件未成立及原因"（如"不涉及人际博弈，无玩家画像"）。台账**不设豁免状态**——守卫覆盖全部 47 行（行按需增减），无任何跳过机制
5. **安全红线不可绕过**：输掉核心资产的重大风险、系统性风险 → 立即阻塞（见 B-3），无论主公是否在线

### B-1 状态机定义


### B-2 转移守卫（守卫 = 查台账；无豁免，产物行全 ✓ 方可推进）

| 转移         | 前置条件（活动行全 ✓）                | 后置动作                            |
| ---------- | --------------------------- | ------------------------------- |
| 接令 → 联想    | L01\~L03 ✓；目标已确认或假设已显式标注    | 核验产物已交代                         |
| 联想 → 研究    | L04\~L08 ✓                  | 指标轴转作变量筛选范围                     |
| 研究 → 规划    | L09\~L23 ✓；**若触发外审须胜诉**     | 可操作变量注入通路候选                     |
| 规划 → 指挥    | L24\~L37 ✓；冲突已裁决；**红线 = 0** | 按里程碑拆子任务                        |
| 指挥 → 复盘    | L38\~L44 ✓；**备份先行**         | 收集产物备审计                         |
| 复盘 → 下一轮   | L45\~L47 ✓；闭环索引已登记          | CARRY 引导写入 → 归档 → 清台账 → CYCLE++ |
| 任意 → BLOCK | STUCK = 3/3（连续三次失败）         | 交主公，严禁带病推进                      |

### B-3 熔断与阻塞

- **熔断**：任何阶段连续 3 次失败 → BLOCK。
- **阻塞**：重大/系统性风险（红线）→ 立即阻塞，**无论主公是否在线**。
