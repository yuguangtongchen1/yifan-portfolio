# 张一帆｜AI 产品作品集

围绕 AI 产品、Agent、AIGC 内容生产与行业智能化的项目作品集。

网站包含六条简历核心项目线、六篇公开技术文章、19 条新闻与机构报道，以及完整项目影像库。影像库收录正式资料目录中的 443 张项目图片，视频文件未纳入。

## 本地运行

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build
```

素材目录更新后可运行 `npm run sync:gallery` 重建兼容 WebP 影像库；运行 `npm run sync:articles` 可同步可直接访问的微信文章封面。
